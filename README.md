# DBTandBigquery-Integration

**Project Overview:**

In this project, I set up and implemented an end-to-end dbt data modeling pipeline using BigQuery to build confidence in modern data engineering workflows.

**Steps Implemented:**

1) _**Created a dbt Cloud account**_ and set up a new project.
2) _**Created a BigQuery project**_ on GCP and configured:

   --> A _**service account**_
   
   --> Generated and used the _**JSON Key**_ to connect BigQuery with dbt Cloud.
   
4) _**Integrated Git**_ with dbt Cloud for version control of all dbt models and configuration files.
5) _**Explored default example models**_ automatically generated by dbt to understand their structure, materializations, and test configurations.
6) Ran dbt run commands to build the example models and _**validated their successful creation in BigQuery.**_
7) Used a _**public dataset**_ (dbt-tutorial) _**available in BigQuery**_ to practice data modeling.
8) Created a _**custom model (table) named**_ "customers" by writing an SQL script in dbt to pull the desired data from the bdt-tutorial dataset.
9) Developed and implemented _**Tests**_ to validate data quality, such as not_null and unique constraints.
10) _**Created a dbt Job**_ in dbt Cloud and ran it successfully to build and test models in an automated deployment workflow.
11) _**Generated dbt documentation**_, including model descriptions, tests, and lineage graphs, to demonstrate best practices in data engineering documentation.
