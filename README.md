# DBTandBigquery-Integration

**Project Overview:**

In this project, I set up and implemented an end-to-end dbt data modeling pipeline using BigQuery to build confidence in modern data engineering workflows.

**Steps Implemented:**

1) ***Created a dbt Cloud account*** and set up a new project.
2) Created a BigQuery project on GCP and configured:
   --> A service account
   --> Generated and used the JSON key to connect BigQuery with dbt Cloud.
3) Integrated Git with dbt Cloud for version control of all dbt models and configuration files.
4) Explored default example models automatically generated by dbt to understand their structure, materializations, and test configurations.
5) Ran dbt run commands to build the example models and validated their successful creation in BigQuery.
6) Used a public dataset (dbt-tutorial) available in BigQuery to practice data modeling.
7) Created a custom model (table) named customers by writing an SQL script in dbt to transform raw data into a cleaned and structured table.
8) Developed and implemented tests to validate data quality, such as not_null and unique constraints.
9) Created a dbt job in dbt Cloud and ran it successfully to build and test models in an automated deployment workflow.
10) Generated dbt documentation, including model descriptions, tests, and lineage graphs, to demonstrate best practices in data engineering documentation.
